Privacy Policy

Last updated: November 2026

1. Project Scope

This application is an academic project developed for the B.E. Computer Science and Engineering 5th Semester Mini Project evaluation. It is not a commercial product or service.

2. Data Collection

This application does not collect any personal data from users. No login credentials, names, email addresses, or other personally identifiable information is requested or stored.

3. Server Monitoring Data

The application monitors simulated server instances running on localhost. Monitoring data includes CPU usage, RAM usage, response times, and server health status. All monitoring data is stored locally in an SQLite database file on the host machine.

4. Cookies and Tracking

This application does not use cookies for tracking purposes. No analytics scripts, advertising trackers, or third-party tracking services are integrated into this application.

5. External Communication

This application runs entirely on localhost. No data is transmitted to external servers, cloud services, or third-party APIs. The only external resources loaded are CDN-hosted CSS and JavaScript libraries (Bootstrap, Chart.js, Socket.IO, Font Awesome) for the dashboard interface.

6. Data Retention

All data generated by this application is temporary and intended for demonstration purposes only. The SQLite database and log files persist only on the local machine and can be deleted at any time by removing the project directory.

7. Contact

This project was developed as part of an academic curriculum. For questions regarding this privacy policy, contact the project team through the supervising faculty at the Department of Computer Science and Engineering.
